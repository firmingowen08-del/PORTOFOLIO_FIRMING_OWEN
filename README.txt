# OWEN — Portfolio Publikasi & Dokumentasi

## Struktur
- index.html
- style.css
- script.js
- assets/hero.jpg
- assets/dokumentasi-01.jpg
- assets/dokumentasi-02.jpg

## Cara menjalankan
1. Extract folder.
2. Buka `index.html` di browser.
3. Untuk mengganti foto, masukkan foto baru ke folder `assets/`, lalu ubah `src` pada `index.html`.

## Catatan
Website ini sengaja dibuat tanpa framework agar mudah diedit. Semua warna, teks, ukuran, animasi, kategori, dan layout bisa diubah langsung dari HTML/CSS/JS.
